# Immersive-HUD-for-OpenMW
Immersive HUD for OpenMW with three modes (Full-Hud, only crosshair, deactivated Hud) Object Tooltip / Message Box / Interactive Message Box are always active
Known limitation:
F11 hides the regular OpenMW HUD, but persistent information elements
(Object Tooltips and Message Boxes) remain visible.

Use H for the intended three HUD modes.
